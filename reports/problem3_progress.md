## 1. 题目要求

男胎 Y 染色体浓度达标时间受多种因素（身高、体重、年龄等）影响。综合考虑这些因素、
检测误差和胎儿 Y 染色体浓度达标比例（≥4%），根据男胎孕妇的 BMI 给出合理分组及每组
最佳 NIPT 时点，使孕妇潜在风险最小，并分析检测误差对结果的影响。

## 2. 建模方案（LTM v3.0，经人类 revise 一轮）

### 2.1 主交付定义

- 个体最佳时点：**约束风险最小化语义** `t_p,i = inf{t∈[10,25]: π_marg(t,x_i)≥p}`，主值 p=0.80；
  当 r_delay 严格递增且 π_marg 单调不减时，与首穿时点等价（0.1 周网格数值断言单调性）。
- 组推荐时点：组级约束首穿 `t_g = inf{t: π_g(t)≥0.80}`，同时报告组内个体 t_p 中位数。
- argmin 三项软损失 `L = r_delay + ρ(1−π_marg) + γ·κ_σ` 降为二级参考列 t*（ρ∈{0.5,1,2}，γ∈{0,0.5,1,2}）。

### 2.2 模型结构（二元-连续双通道）

- 主模型：logit GLMM 对达标事件 `D_ij=1(y_obs≥0.04)`，随机截距 + 中心化孕周随机斜率。
- 辅助模型：Beta-GAMM 对连续 Y 浓度，用于校准达标比例并传播测量误差。
- 协变量：默认"体重+身高+年龄+IVF"（体重优先），强制比较 BMI / 体重 / 身高+体重 /
  三者全入四种形态（AIC/BIC/孕妇层 CV/1SE 选型）；残差化仅作敏感性。

### 2.3 分组与验证

- BMI 数据驱动分组 K∈{2,3,4}，候选边界 {24,26,28,30,32,34,36}，**1SE 规则选 K 与边界**；
  报告组间时点差异 CI、组内异质性下降、损失改进、边界 bootstrap 重现频率。
- 双通道误差：通道 A=σ_tech 浓度测量误差卷积（κ_σ、t 偏移）；技术失败类（GC 平台偏差）
  独立敏感性；通道 B=孕妇层 cluster bootstrap（B=100）出主区间。
- 报告个体 t_p 分布形态（直方图/分位数/双峰检测）；窗口端点右删失语义。

## 3. 文献吸纳要点（revise 依据）

- Qiao 2019：12.5–20 周 FF 增速仅 0.083%/周 → 平台期风险，主交付改首穿语义。
- Hou 2015 / Q1 实测：体重优于 BMI → 四种协变量形态比较，不默认残差化。
- Ashoor 2013 / Wright 2015：达标比例对照外部量级（P(FF<4%) 随体重非线性加速、FF=4% 检出率约 62%）。
- Mousavi 2022 荟萃矛盾：主动讨论"二元达标事件与连续 FF 受不同因素支配"。
- Palomaki 2018：区分低 FF 与技术失败 → 双通道误差分类。
- Deng 2023：核型不改变 FF → AE 事后标签仅作敏感性，禁止进入实时决策主模型。
- McKanna FFBR / Scheffer 2021：按协变量建 FF 分布的方法对照与 r_delay 临床依据。
